# 🚀 Electron Vue Vite Demo - 项目介绍

## 🎯 项目概述

这是一个**生产就绪**的 Electron + Vue 3 + Vite 项目示例，展示了如何构建一个同时支持浏览器和桌面环境的现代化应用。

### 核心特点

🎨 **智能环境检测**  
自动识别浏览器和 Electron 环境，提供差异化的用户体验。

🔗 **HTTP 请求代理**  
通过 IPC 调用 Node.js 处理 HTTP 请求，完美解决跨域问题。

⚡ **独立部署能力**  
Web 项目可以单独打包部署，无需依赖 Electron。

🔒 **安全性保障**  
遵循 Electron 安全最佳实践，使用 contextBridge 隔离上下文。

📦 **一键开发启动**  
提供便捷脚本，一条命令启动完整开发环境。

## 🔥 核心功能展示

### 1. HTTP 请求代理

```typescript
// 统一的 HTTP 客户端接口
import { http } from '@/utils/http'

// 在任何环境下都能正常工作
const response = await http.get('https://api.github.com/users/github')

// Electron 环境：通过 IPC 调用 Node.js
// 浏览器环境：使用 fetch API
```

**解决的问题：**
- ❌ CORS 跨域限制
- ❌ 浏览器安全策略
- ❌ 网络功能受限

**带来的价值：**
- ✅ 完整的网络访问能力
- ✅ 统一的开发体验
- ✅ 更好的错误处理

### 2. 智能环境检测

```typescript
import { isElectron, getElectronAPI } from '@/utils/env'

// 根据环境提供不同功能
if (isElectron()) {
  const api = getElectronAPI()
  await api.file.selectAndRead()
} else {
  // 浏览器降级方案
  showDownloadPrompt()
}
```

**自动处理：**
- 路由模式选择（hash vs history）
- HTTP 请求方式（IPC vs fetch）
- 功能可用性判断
- 用户界面差异

### 3. 安全的 IPC 通信

```typescript
// Preload 脚本 - 安全暴露 API
contextBridge.exposeInMainWorld('electronAPI', {
  http: {
    request: (config) => ipcRenderer.invoke('http:request', config)
  }
})

// 渲染进程 - 调用 API
const result = await window.electronAPI.http.request(config)
```

**安全措施：**
- ✅ contextIsolation 启用
- ✅ nodeIntegration 禁用
- ✅ 使用 contextBridge
- ✅ 最小权限原则

## 📊 技术架构亮点

### 分层架构

```
┌─────────────────────────┐
│    渲染进程 (Vue 3)      │  用户界面层
├─────────────────────────┤
│  Preload (contextBridge) │  安全隔离层
├─────────────────────────┤
│    主进程 (Electron)     │  系统服务层
└─────────────────────────┘
```

- **环境检测模块**：自动识别运行环境

- **路由守卫模块**：智能访问控制
